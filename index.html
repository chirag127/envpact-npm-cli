envpact-cli

Zero-dependency CLI for a centralized, serverless, Git-backed secrets manager — one private vault, every project, zero infrastructure, $0 forever.

npx envpact-cli --init auto   # create private vault
cd my-project && npx envpact-cli   # resolve refs, write .env
  • One private GitHub repo holds a single secrets.json.
  • Project secrets reference shared secrets via shared.KEY_NAME.
  • Rotate once → every project resolves the new value on next run.
  • Opt-in per-secret age encryption; .env written mode 0600.
